# Estudos em C

Repositório destinado ao estudo da linguagem C, contendo exercícios, anotações e códigos desenvolvidos durante a leitura do livro "C - Completo e Total".

O objetivo deste repositório é documentar minha evolução na linguagem, praticando conceitos fundamentais e avançados através de exercícios e pequenos programas.

## Conteúdos estudados

Até o momento, os principais conceitos abordados incluem:

- Sintaxe básica da linguagem C
- Tipos de dados e operadores
- Estruturas de controle
- Matrizes e strings
- Ponteiros
- Funções
- Structs, unions, enums e typedef
- Entrada e saída pelo console
- Manipulação de arquivos
- Pré-processador
- Compilação separada e organização de projetos
- Alocação dinâmica de memória
- Ordenação e pesquisa
- Estruturas de dados como listas, filas e pilhas

## Organização

Cada pasta representa um tópico ou capítulo estudado, contendo exercícios realizados e exemplos práticos dos conceitos aprendidos.

Exemplo:
Ponteiros/
├── exercícios
└── exemplos

Structs/
├── exercícios
└── aplicações

ES Arquivos/
├── leitura
└── escrita


## Objetivo

Além de consolidar os fundamentos da linguagem C, este estudo serve como base para projetos futuros envolvendo programação de baixo nível, sistemas embarcados e desenvolvimento de software.
